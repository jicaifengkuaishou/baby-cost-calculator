# 养娃成本计算器 - 小程序

一个有趣且实用的微信小程序，帮助准父母计算养育孩子的真实成本。

## ✨ 功能特性

- 📊 **科学计算**：基于真实数据，综合考虑教育、生活、医疗等多维度成本
- 🎯 **个性定制**：根据城市、收入、教育规划等个性化参数精准计算
- 📈 **可视化展示**：直观的图表和数据对比，一目了然
- 🎉 **趣味互动**：问答式体验，生成专属父母画像
- 📤 **分享传播**：一键分享结果到朋友圈

## 💡 核心算法

### 成本计算模型

1. **教育成本**
   - 幼儿园：公立/私立/国际三档
   - 小学-高中：公立/私立/国际三档
   - 本科/研究生/博士：学费+生活费

2. **生活成本**
   - 5档生活水平：极简/基本/舒适/富裕/奢侈
   - 城市系数：一线城市×1.5，二线城市×1.0

3. **课外培养**
   - 5档投入水平：500元-2万元/月

4. **育儿支持**
   - 0-3岁育儿嫂可选：约1万元/月

### 计算示例

```javascript
// 一线城市，舒适型生活，公立小学
总成本 = (教育成本 + 生活成本 + 课外班) × 城市系数 × 孩子数量
```
